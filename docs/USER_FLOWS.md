# User Flows - قَيَّم للعطور

## 1) تدفق العميل (Customer)
### A) تصفح المنتجات
1. الدخول إلى `/`
2. التصفح عبر التصنيفات (Men/Women/Summer/Winter/Best Sellers/Special)
3. فتح `/products/[slug]`
4. عرض الصور والمكونات (Top/Middle/Base) والمقاسات/الأحجام وتقييمات العملاء وتوفر المنتج

### B) إضافة إلى السلة
1. في صفحة المنتج، اختيار الحجم/الvariant المناسب
2. الضغط على "إضافة إلى السلة"
3. الانتقال إلى `/cart`
4. تعديل الكمية/عرض الملخص

### C) إتمام الطلب
1. من `/cart` الانتقال إلى `/checkout`
2. إدخال بيانات العميل + طريقة التواصل/الشحن (حسب سياسة المشروع)
3. إرسال الطلب
4. ظهور صفحة تأكيد (اختياري) + تحديث حالة الطلب في لوحة الإدارة

### D) المفضلة (Wishlist)
1. من صفحة المنتج اختيار "إضافة للمفضلة"
2. زيارة `/wishlist`
3. عرض المنتجات المحفوظة واتخاذ إجراء (سلة/إزالة)

### E) البحث والتصفية
1. استخدام البحث من الهيدر (اسم/نوع)
2. تصفية حسب النوع والسعر والفئة
3. عرض قائمة المنتجات وتحديث نتائج التصفية

### F) مشاركة المنتج
1. زر مشاركة من صفحة المنتج
2. مشاركة عبر وسائل التواصل (Social share)

## 2) تدفق لوحة الإدارة (Admin)
### A) تسجيل الدخول
1. فتح `/admin`
2. تحقق صلاحيات Admin

### B) إدارة المنتجات
1. فتح `/admin/products`
2. Create / Edit / Delete
3. رفع صور متعددة وربطها بالمنتج
4. ضبط حالة توفر المنتج + بيانات المكونات والمقاسات والأسعار

### C) إدارة التصنيفات
1. فتح `/admin/categories`
2. إنشاء/تعديل/حذف التصنيفات وربطها بالمنتجات

### D) إدارة الطلبات
1. فتح `/admin/orders`
2. عرض قائمة الطلبات حسب الحالة
3. فتح `/admin/orders/[id]`
4. تغيير الحالة:
   - جديد
   - قيد التجهيز
   - تم الشحن
   - مكتمل
   - ملغي

### E) إدارة المخزون
1. فتح `/admin/inventory`
2. تعديل كميات variants/أحجام المنتجات
3. منع بيع الكميات غير المتوفرة (حسب سياسة التنفيذ)

### F) الإحصائيات
1. فتح `/admin/analytics`
2. عرض أفضل المنتجات مبيعًا
3. عرض زيارات/طلبات (إن تم تتبّعها لاحقًا)
